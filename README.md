# 🏦 BankingApplication

A lightweight, educational C# implementation of a core banking system.

## 🎯 Purpose
This project was created as a sandbox to explore the fundamental logic of financial transactions, account management, and state handling within the .NET ecosystem. It serves as a playground for implementing core banking logic without the overhead of complex enterprise frameworks.

## 🚀 Project Goals
The primary objective is to build a functional, transparent, and extensible banking engine. 

**Current Focus Areas:**
*   **Core Logic:** Implementing basic CRUD operations for user accounts.
*   **Transaction Integrity:** Exploring how to handle deposits, withdrawals, and balance updates.
*   **Educational Growth:** A hands-on approach to mastering C# syntax, object-oriented principles, and error handling.

> [!NOTE]
> **Disclaimer:** This is an educational project and is **not** intended for real-world financial use. It is currently in an early development stage and does not yet meet industry-standard security or concurrency requirements.

## 🛠️ Tech Stack
* **Language:** C#
* **Runtime:** .NET (Core)
* **Architecture:** Console-based (Initial Phase)

## 🚧 Roadmap & Future Improvements
As this project evolves, I aim to move away from a "simple" implementation toward industry standards:
- [ ] **Security:** Implementing encryption for sensitive data.
- [ ] **Data Persistence:** Moving from in-memory storage to a SQL database (Entity Framework Core).
- [ ] **Concurrency:** Handling multiple simultaneous transactions safely.
- [ ] **Architecture:** Transitioning to a Clean Architecture or Onion Architecture pattern.
- [ ] **Testing:** Adding Unit Tests (xUnit/NUnit) to ensure transaction reliability.
